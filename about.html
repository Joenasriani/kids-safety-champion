Safety Champion Adventure

Play the game · Source repository

What it is

Safety Champion Adventure is a five-level letter-assembly safety game developed as part of a multi-game interactive children’s edutainment activation in the UAE.

Game rule

Each run selects two one-word prompts, two two-word prompts and one three-word prompt from the built-in safety question banks. The answer letters are shuffled for each level.

safety prompt → shuffled answer letters → ordered letter selection → completed answer → next level

The most recently entered letter can be removed by selecting its filled slot. An incorrect completed answer reloads the same level.

Safety topics

The current prompts cover unknown pills or substances, medicine supervision, strangers, unsafe offers, trusted adults, and unknown online contacts.

Activation context

This game belongs to the same kids-* game set developed for the multi-game interactive children’s edutainment activation in the UAE.

Evidence boundary

The repository implements safety prompts and answer reconstruction. It does not contain evidence measuring safety knowledge retention or behavior change outside the game. The in-game “Certified Safety Champion” message is a completion reward inside the game.
