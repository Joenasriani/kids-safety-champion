# Safety Champion Adventure

Play: https://kids-safety-champion.vercel.app/

Safety Champion Adventure is a five-level letter-assembly safety game.

## How it plays

Each run builds a five-question mission from three prompt banks:

- two one-word answers;
- two two-word answers;
- one three-word answer.

For each level, the answer letters are shuffled. The player selects letters in order to reconstruct the response. The most recently entered letter can be removed by selecting its filled slot.

**safety prompt → shuffled letters → ordered selection → completed answer → next level**

An incorrect completed answer reloads the same level. Completing all five levels reaches the Safety Champion result screen.

## Safety topics

The current prompts include unknown pills or substances, medicine supervision, strangers, unsafe offers, trusted adults and unknown online contacts.

## Content note

The in-game “Certified Safety Champion” message is a completion reward inside the game, not an external credential or validated safety assessment.
